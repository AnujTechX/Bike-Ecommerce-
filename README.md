# Bike Ecommerce

## About
Bike Ecommerce is a React-based web application for exploring bikes and scooters.

## Features
- Browse bikes and scooters
- Search bikes
- Compare bikes
- Wishlist
- Add bikes to garage
- Bike booking
- Checkout
- User profile
- Orders section

## Technologies Used
- React.js
- JavaScript
- CSS
- Redux
- Vite
